# CS2 回放整理工具（cs2-replay-organizer）

A one-click Windows tool that extracts, pairs and renames Counter-Strike 2 match replays, so you can watch them in-game without any manual file juggling.

把 Steam 个人资料页下载的比赛回放压缩包，自动"解压 → 放进游戏回放文件夹 → 与游戏生成的配置文件配对改名"，让你直接在 CS2 里观战。

## 它解决什么问题

在 CS2 里观看自己的比赛回放，官方流程比较绕：先在网页点"下载录像"拿到压缩包，手工解压、改名、移动，再进游戏点一次"下载"，最后还要把两个文件改成同名，才能在游戏里刷新观看。手动做一次要好几步，容易出错。

本工具把中间步骤全部自动化，只保留两个必要的点击（网页下载 + 游戏内下载）。

## 功能特性

- **双击即用**：自动找到刚下载的回放压缩包（`.dem.bz2`），静默解压。解压优先使用 Windows 自带引擎（和右键"全部解压缩"是同一个），失败时才回退到本机已安装的 7-Zip，不需要额外安装软件。
- **自动配对**：按文件名中的「比赛编号_回放编号」找到同一局的 `.dem` 与 `.info`，只把 `.dem` 改成与 `.info` 完全同名。
- **等待机制**：录像放好后弹窗提醒，脚本最多等你 3 分钟（可设置）；检测到游戏内下载的 `.info` 后自动收尾，并弹窗 + 响铃提示"可以看了"。
- **安全可靠**：`.info` 全程只读；同名不同大小绝不覆盖；压缩包没下载完会明确提示且不做任何改动；重复运行无副作用。
- **不常驻**：双击才运行，不装服务、不设开机启动、不需要管理员权限，也不与游戏进程发生任何接触。
- **整理归档**：整理成功后压缩包默认移入回收站（可在设置里改为保留）。

## 使用流程

1. Steam 里打开：个人资料 → 游戏 → CS2 我的统计数据 → 优先权模式比赛 → 找到那一局 → 点"下载录像"（压缩包会下载到系统"下载"文件夹）。
2. 双击 `1-整理回放.cmd`：脚本自动解压并把录像放进游戏回放文件夹，然后弹窗提醒。
3. 回到游戏：观战(Watch) → 你的比赛 → 找到这一局 → 点"下载"（只下载很小的 `.info`）。3 分钟内脚本会自动把 `.dem` 改成与 `.info` 同名，并弹窗提示"可以看了"；回到游戏刷新即可观战。

不想等待：在脚本窗口里按任意键跳过，稍后再双击一次即可收尾，不需要重新下载。

也可以把压缩包（或已经手动解压出来的 `.dem`）直接拖到 `1-整理回放.cmd` 上。

## 工作原理

Steam 网页下载的压缩包文件名形如 `<比赛编号>_<回放编号>.dem.bz2`，解压得到同名 `.dem`。游戏内点击"下载"后，游戏会在回放文件夹生成 `<比赛编号>_<回放编号>_<版本>.dem.info`。工具用「比赛编号_回放编号」作为钥匙把两者配对，只需要把 `.dem` 改成 `match730_..._<版本>.dem`（即 `.info` 去掉 `.info` 后的名字）。`.info` 始终保持原样。

## 系统要求

- Windows 10 / Windows 11（自带 Windows PowerShell 5.1）
- Steam 版 Counter-Strike 2
- 游戏位置自动探测：注册表里的 Steam 安装路径 + Steam 库配置文件 + 常见默认安装位置；也可以手动在设置里填写

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `1-整理回放.cmd` | 双击入口，支持把压缩包 / `.dem` 拖进来 |
| `脚本/整理回放.ps1` | 核心逻辑 |
| `设置.txt` | 首次运行自动生成：等待分钟数、压缩包处理方式、下载 / 回放文件夹、解压方式、7-Zip 路径 |
| `使用说明.txt` | 面向普通用户的三步说明 |
| `创建桌面快捷方式.cmd` | 在桌面生成入口图标 |
| `整理日志.txt`、`已处理记录.txt` | 运行记录，自动生成，可随时删除 |

> `设置.txt`、`整理日志.txt`、`已处理记录.txt`、`临时/` 属于个人数据与运行产物，已被 `.gitignore` 排除，不会上传。

## 设置项说明

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| `等待分钟` | `3` | 录像放好后等待你完成"游戏内点击下载"的时长；`0` = 不等待（稍后再双击一次收尾） |
| `压缩包处理` | `回收站` | 整理成功后压缩包的归宿，可改为 `保留` |
| `下载文件夹` | 自动探测 | 回放压缩包存放位置（通常是系统"下载"文件夹） |
| `回放文件夹` | 自动探测 | 游戏回放文件夹（结尾是 `game\csgo\replays`） |
| `解压方式` | `自动` | `自动` = 系统解压优先、7-Zip 兜底；也可强制 `系统` / `7-Zip` |
| `7Zip路径` | 自动探测 | `7z.exe` 完整路径，留空自动探测 |

## 常见问题

- **提示"这次没有发现新的回放压缩包"**：确认已在 Steam 点过"下载录像"、压缩包下载完成且在系统"下载"文件夹；也可以把压缩包直接拖到工具上。
- **提示"压缩包可能还没下载完"**：等下载完成后再双击一次即可；工具不会删除或改动没下载完的文件。
- **提示"回放文件夹里已有同名但不同的文件"**：工具不会覆盖，新的一份会另存为 `xxx.new.dem`，可自行决定保留哪一份。
- **提示"没有找到回放文件夹"**：在 `设置.txt` 里手动填写回放文件夹完整路径。
- **不想等待 3 分钟**：把 `等待分钟` 设为 `0`，完成游戏内点击后再双击一次工具收尾。
- **移动文件夹后桌面图标失效**：重新双击一次 `创建桌面快捷方式.cmd` 即可。

## 安全说明

- 只读写两个位置：系统"下载"文件夹与游戏回放文件夹（游戏自身也会写入的位置），不修改游戏程序与配置。
- `.info` 文件只读，不改名、不移动、不删除；只把 `.dem` 改成与它同名。
- 不与游戏进程交互、不注入、不读取游戏内存。
